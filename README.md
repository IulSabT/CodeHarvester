# User Manual

## 1. Project Description

**CodeHarvester** is a Python-based software utility designed to automate the auditing and documentation process of software projects, with a strong focus on the React Native ecosystem. The application recursively scans project directories while ignoring system or configuration folders (such as `node_modules` or `.git`), and analyzes relevant source files (`.js`, `.jsx`, `.ts`, `.tsx`).

### Main Objectives:

* Providing a quick overview of code structure and complexity.
* Automatically identifying `TODO` and `FIXME` comments.
* Mapping external and internal dependencies.
* Evaluating function complexity and decision structures to pinpoint areas requiring refactoring.

---

## 2. Abbreviations and Symbols Used

The reports generated by the application and this manual use the following abbreviations and markers:

### Report Symbols:

* **`[LIB]`** – Imported external library.
* **`[INT]`** – Internal import.
* **`[Comp]`** – Detected React component.
* **`[!]`** – Marker for `TODO` or `FIXME`.
* **`[f]`** – Identified function or method.
* **`useState`** – React hook used for local state management.

---

## 3. Installation Instructions

CodeHarvester is a standalone Python script that relies exclusively on standard libraries. Installation is streamlined and requires no additional configurations.

### System Requirements:

* Operating System: Windows, macOS, or Linux.
* Python version **3.x** installed.

### Installation Steps:

1. Verify your Python installation using the command: `python --version`.
2. Create a new file, for example, `main.py`.
3. Copy the application's source code into this file.
4. Save the file. No additional package installations are required.

---

## 4. Usage Instructions and Commands

The application runs from the terminal and features an interactive menu.

### 4.1 Starting the Application

Run the command:

```bash
python main.py

```

### 4.2 Initial Configuration

Upon startup, the application prompts for:

* The path to the React Native project.
* The output folder for reports (default: `rapoarte_proiect`).

### 4.3 Command Menu

1. **Extract Comments** – Scans files and extracts comments. Result file: `1_comentarii.txt`
2. **Extract Imports** – Identifies import statements. Result file: `2_importuri.txt`
3. **Extract Components** – Detects React components. Result file: `3_componente.txt`
4. **Extract TODOs** – Searches for `TODO` and `FIXME`. Result file: `4_todos.txt`
5. **Extract STATE** – Identifies `useState` hook usages. Result file: `5_state_data.txt`
6. **Extract Functions** – Lists defined functions. Result file: `6_functii_logica.txt`
7. **Advanced Analysis** – Performs cyclomatic complexity analysis. Result file: `7_analiza_avansata.txt`
8. **Exit** – Closes the application.
